# Smart Energy Consumption Advisor

## 1. Problem Statement

Many households know their monthly electricity bill but do not know which appliances are using more electricity. This makes it difficult to control usage and stay within a fixed budget. The project provides appliance-wise consumption and cost estimates, identifies high-consuming appliances, checks the expected bill against the budget, and gives simple suggestions to reduce unnecessary electricity use.

## 2. Scope of the Project

The project focuses on estimating household electricity consumption using appliance wattage and daily usage. It calculates monthly units, estimated cost, total bill, and appliance rankings. It also checks the user's budget and provides basic saving recommendations. Appliance data can be stored in a CSV file. The current version is designed for a single household and works through the command line.

## 3. Target Users

* **Households:** To understand appliance-wise electricity usage.
* **Homeowners:** To monitor estimated bills and monthly budgets.
* **Students:** As a simple practical energy-management project.
* **Small Residential Users:** To find appliances with relatively high consumption.

## 4. High-Level Features

* **Appliance Management:** Add appliance name, wattage, and daily usage.
* **Consumption Calculation:** Calculate monthly electricity use in kWh.
* **Bill Estimation:** Calculate appliance-wise and total estimated cost.
* **Consumption Ranking:** Arrange appliances by monthly usage.
* **Budget Check:** Compare the estimated bill with the set budget.
* **Usage Analysis:** Identify appliances contributing more to consumption.
* **Saving Suggestions:** Give basic recommendations based on usage.
* **CSV Storage:** Save appliance and consumption data locally.
* **Report Generation:** Display the main consumption and cost details together.
